Project purpose

Bring product browsing, ordering, and store administration together in one PHP/MySQL application.

Customer and admin workflows

Customers can filter the catalogue, select product variants, manage a wishlist, apply coupons, and place cash-on-delivery orders. The admin panel manages products, categories, orders, and customer messages.

Application structure

Built without a PHP framework, with database queries grouped into models, shared page components, and separate form handlers. The project guide documents prepared statements, password hashing, CSRF protection, and separate customer and admin roles.

Current scope

Checkout supports cash on delivery. Online payment gateways, including M-Pesa, are not connected yet. Running the project requires a PHP server and MySQL database.
