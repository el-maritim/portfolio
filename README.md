# Elton Langat — Portfolio

A personal portfolio covering software development, networking, and systems administration, including Verve E-commerce and a Windows/Linux infrastructure lab.

## View locally

Open `index.html` in your browser. It opens `portfolio-network.html`, the main portfolio page. The full lab report is available from the projects section.

## Files

- `portfolio-network.html`: portfolio content
- `style.css`: shared design and responsive styles
- `script.js`: interactive terminal and homepage behavior
- `scroll.js`, `motion.js`, `navigation.js`: scrolling, pointer interactions, and mobile navigation
- `lab-report.html`, `lab-report.css`: full lab report with embedded screenshots
- `elton-logo.png`: browser tab icon

No build step or dependencies are required. Google Fonts requires an internet connection; system font fallbacks are provided.

## Hosting

Serve these files from any static web host. `index.html` provides the default entry point. For GitHub Pages, select the repository's publishing branch and its root directory in Settings → Pages.
